October 27, 2026 · Capsid 1.1.0

Compare, return, pick up the thread.

  • Compare on the Shelf. View pictures side by side with linked zoom, wipe between matching image sizes, and step through changes in text files.
  • Project Workspaces. Each project remembers its last conversation, up to four pinned references and a Working Note.
  • Eight more specimens. Capillary electrophoresis, Microtome ribbon, Droplet coalescence, Slime mold maze, Möbius strip, Bayesian update, Fern unfurling and Diatom bring this release to 549. Optional short sequences tell little stories; the new specimens can settle with a closing gesture.
  • A clearer way back. Show Where It Came From opens the source reply. Documents on the Shelf show their words. A short What’s New window introduces the release.
  • Your words stay put. Fixes protect phone drafts, kept README additions and legends while files reload.

Nidus 0.3.0

Oct 6, 2026

Nidus 0.3.0 lets assistants, launchers and Shortcuts drive focus sessions, with real answers.

  • Shortcuts. Start Focus can start a saved setup. New: Add Focus Time, which says how many minutes it actually added. Get Focus Status now says whether a session is running, paused or on a break, whether it's open-ended or strict, and whether it's blocking right now.
  • For scripts and assistants. Run Nidus Command takes one JSON request (status, setups, start, addTime, end) and answers in JSON. A retry with the same request id gets the first answer back instead of doing it twice.
  • Launch links. Right-click a setup and choose Copy Launch Link for a nidus:// link that starts just that setup, by id, so renaming it doesn't break the link.
  • Optional extras in the repository's integrations folder: Raycast Quicklinks, and a small assistant skill (for ChatGPT on your Mac, Codex and similar) that starts a setup, adds time or says how long is left.
  • docs/automation.md covers Shortcuts, links, Raycast, Alfred, BetterTouchTool and the JSON command.

The same rules apply however a session is started: a strict session can't be ended from outside, a start never replaces a session that's on, and asking for status changes nothing. Nidus still never connects to the internet.

Nidus 0.2.0

Oct 5, 2026

Nidus 0.2.0 is the biggest update yet.

  • Setups. Save what you start often, like "Deep work: 90 minutes, only Xcode, strict", and start it in one click from the popover or the right-click menu.
  • Schedules. "Weekdays, 9 to 12" starts a session on its own. A card a minute before lets you skip it or start now.
  • Any length. Type it: "40", "1h30", "until 3:30". Or end a session when your next calendar event starts (Calendar access is asked the first time, and read only on this Mac).
  • Part of a site. Block youtube.com/shorts or reddit.com/r/all and leave the rest.
  • Brave and Chromium join Safari, Chrome and Opera Air.
  • A pause before a snooze. Settings can make Snooze wait 10 or 30 seconds first.
  • Shortcuts and links. Start Focus, End Focus, Toggle Focus and Get Focus Status in Shortcuts, plus nidus://start, end, toggle and popover links. A strict session can't be ended by either.
  • Stats. Export your history as CSV or JSON, a recap card on Mondays, and a calmer Stats page.
  • Quitting puts tabs back. Quit mid-session and blocked tabs return to their pages; they're blocked again when Nidus opens.
  • A new look in places. Settings in toolbar tabs, the popover shows when a session ends and how often something was blocked, and the finish card asks "Did you finish?" first.
